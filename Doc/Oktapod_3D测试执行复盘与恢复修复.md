## 人工恢复流程

1. 更新服务后刷新原项目页面，展开输入框上方执行计划，查看具体被拒工具及原因。
2. 点击“恢复任务”：后端在同一任务内新增修正模型步骤，保留已有完成项与文件。模型需要换用合法工具或正确参数；禁止动作不会因此得到授权。
3. 如新动作需要审批，审批卡将列出实际动作，用户在该卡操作；没有审批卡的确定性拒绝不能靠批准解决。
4. 恢复请求失败时，页面显示错误；若模型再次耗尽自动修正，保留受阻状态与新证据，不宣称恢复成功。

现有任务的旧 Artifact 是当时的证据快照，不会随工作区编辑自动更新。交付前需重新登记最终文件并完成浏览器渲染验证；CDN three.js 与 ES Module 多文件应用需要实际静态站点，不适用于现有单文件 HTML 隔离预览的全部能力声明。
